# 夢叶のAIニュースピック

AIの主要プレイヤー11者の発信を毎朝自動で集め、Claude Haikuで「要約+個人ビジネスへの影響」を作って静的サイトとして公開する仕組みです。

## 仕組み

```
GitHub Actions(毎朝6時)
  → 許可リストのソースだけ収集(タイトル+短い概要のみ。本文は取らない)
  → Claude Haikuで重要度判定・見出し書き直し・要約・影響コメント
  → 安全チェック(類似度・文字数・出典) → 不合格は書き直し → それでもダメなら保留
  → data/ に保存(過去ログが貯まる)
  → site/ を生成して GitHub Pages に公開
```

## 費用の目安

- GitHub Actions / GitHub Pages:公開リポジトリなら無料
- Claude Haiku:1日40件を上限にしているので、月数百円程度の見込み
  (`config/sources.yaml` の `max_items_per_run` で上限を調整できます)

## セットアップ(初回のみ)

1. このフォルダを GitHub に **公開(Public)リポジトリ** としてアップロード
2. Settings → Secrets and variables → Actions で `ANTHROPIC_API_KEY` を登録
3. Settings → Pages → Source を **GitHub Actions** に設定
4. `config/sources.yaml` を開き、各ソースを確認して `approved: true` にする(下のチェックリスト参照)
5. `config/sources.yaml` の `site.cta.url` をLINE登録URLなどに差し替え、`base_url` も設定
6. Actions タブ → daily-news-pick → Run workflow で手動実行して動作確認

## ソースの許可チェックリスト(人が一度だけ確認)

各ソースについて、以下を確認してから `approved: true` にしてください。

- URLをブラウザで開いて、記事一覧やRSSが表示されるか
- 利用規約に「自動取得(クローリング)の禁止」がないか
- 利用規約に「非商用・個人利用に限る」がないか(集客目的の無料配布もビジネス利用とみなされる前提で判断)
- robots.txt で対象ページの取得が禁止されていないか(HTML型のソース)

ニュース検索系(`news-` で始まるソース)は、規約上の制限がある可能性が高いので特に注意してください。使えない場合は外しても、企業の公式発表とYouTubeで主要な動きは拾えます。

## 自動の安全装置

| 装置 | 内容 |
|---|---|
| 入力制限 | AIにはタイトルと概要(300字まで)だけを渡す |
| 見出し書き直し | 元の見出しは使わず、事実ベースで新しく作る |
| 類似度チェック | 元文との文字4-gram一致率35%超、または18字以上の連続一致で不合格 |
| 文字数上限 | 見出し40字・要約150字 |
| 出典必須 | 出典名と元記事リンクがないものは公開しない |
| 独自コメント | 「個人ビジネスへの影響」を必ず付ける |
| 保留 | 2回書き直しても不合格なら公開しない |
| ログ | `data/logs/日付.json` に判定結果を記録 |

基準値は `config/sources.yaml` の `safety` で調整できます。

## 運用

- 月1回ほど `data/logs/` の保留(`"status": "held"`)と公開済み記事をざっと確認
- 公開された記事を消したいときは `data/items/日付.json` から該当部分を削除 → `python main.py --build`
- デザイン確認は `python main.py --demo`(APIもネットも不要。`site_demo/` に出力)
- リポジトリに長期間動きがないと定期実行が止まる仕様があります。止まっていたら Actions タブから再有効化してください

## 限界

- 類似度チェックは同じ言語同士で強く効きます。英語の記事を日本語に要約する場合は、入力を短い概要に限ることと文字数上限が主な防波堤になります
- この仕組みは法的な判断を代わりに行うものではありません。気になる記事があれば手動で削除してください
